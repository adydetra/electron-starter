# Project Status & Roadmap

Current state, supported features, and technical notes for `electron-starter`.

## Implemented Scope

- **Frameless Window**: Custom frameless window with interactive topbar and window controls.
- **Electron 43 + React 19**: Modern desktop architecture with fast Vite HMR.
- **Secure IPC**: Context-isolated bridge via `preload.cjs`.
- **Tailwind CSS v4**: Desktop UI styled with native utility classes.
- **NSIS Windows Packaging**: Configured with `electron-builder` and custom installer graphics.
- **State Management**: Zustand integration for reactive client state.

## Roadmap

- [ ] macOS and Linux packaging configuration.
- [ ] Auto-updater support via `electron-updater`.
- [ ] System tray integration and notifications.
